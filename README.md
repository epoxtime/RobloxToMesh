# RobloxToMesh
Convert Roblox models into fully textured meshes!


## HOW TO USE:
- When you have made a Roblox model out of parts (Or colored a separated mesh in studio, that works too), group them all together.
- In the explorer, right-click on the model and select "Save / Export" > Export as Obj
- Run the application, select your file(s), and hit submit. It will make the mesh and texture for you!
- Import the mesh to Roblox, add a SurfaceAppearance, and under 'ColorMap', select the image file.
- Enjoy!

The texture file is sized automatically and extremely optimized. textures can be as small as 16x16 pixels! (If you only had one color, that is)
